# IMDB-Reviewer
Fine-tuned DistilBERT model for movie review sentiment classification on IMDB reviews

## Results
   - **Accuracy: 84%**
   - Base model: distilbert-base-uncased  
   - Dataset: IMDB movie reviews
   - Training: 3 epochs
   
   ## Technologies
   Python, HuggingFace Transformers, PyTorch, Google Colab
